# ADR-0004: Обновлять инфраструктурные образы с проверкой сохранности данных

PostgreSQL остаётся основной СУБД, major 17 не меняется. Образ Debian bookworm содержит множество устаревших библиотек, включая Perl и libxml2, которые не нужны приложению. Для новых установок выбирается официальный PostgreSQL 17 Alpine, закреплённый по digest. Caddy поставляется отдельным минимальным образом с официальным статическим бинарником, проверяемым по checksum: выпуск upstream уже содержит исправления, но готовый официальный Docker tag ещё не опубликован.

Физический PostgreSQL volume между glibc и musl не переиспользуется. Установщик различает поколения хранения в metadata релиза. Переход bookworm → Alpine выполняется только через `pg_dump` и `pg_restore` в новый именованный volume. Прежний volume сохраняется. Перед остановкой проверяются свободное место и отсутствие целевого volume; после остановки писателей создаётся окончательный согласованный dump. Восстановление завершается до миграций и запуска приложений. Ошибка оставляет журнал и закрывает автоматический повтор; старые данные не удаляются и новая пустая БД не выдаётся за успешное обновление. Обычный rollback через границу поколений запрещён: возврат требует отдельного восстановления с учётом записей, принятых после переключения.

Проверка выпуска включает чистую установку и перенос заполненной БД из старого образа, с проверкой аккаунтов, ключей и событий. Смена locale сопровождается логическим восстановлением индексов; явно заданные пользовательские collations не переносятся без отдельной проверки. Локальный Compose не переключает существующее хранилище автоматически.

High/Critical остаются блокирующими. Допустим только документированный вывод о неприменимости конкретной находки к конкретным компонентам, с ограничением версии и сроком повторной проверки. Общий `ignore-unfixed`, снижение порога и исключение всех системных пакетов запрещены. Полный исходный отчёт сканера сохраняется независимо от результата оценки.
