# Повышать версию SDK только при изменениях его входных файлов

Сервер и npm-пакеты проверяются и доставляются с точным SHA, но номер SDK не является номером серверной версии. Изменения dashboard, worker, инфраструктуры и тестов сами по себе не требуют повышения версии SDK.

Prepare сравнивает входные файлы SDK с последним подготовленным commit: browser, react, cli, встроенный protocol, зависимости, настройки сборки и лицензия. Изменение этих файлов либо отсутствие проверенной предыдущей подготовки повышает patch. Для серверных изменений номер сохраняется; после полного `yarn checks` создаётся пустой commit подготовки с прямым `Release-Source`. Проверка commit допускает только два строгих варианта: прежний patch commit manifests либо пустой server commit с неизменёнными согласованными SDK-версиями.

Публикация по-прежнему сверяет уже существующие npm-архивы с локально собранными. Несовпадение блокирует выпуск; содержимое опубликованной версии не заменяется. Provenance, проверки stale SHA, сканирование образов и совместная проверка установки остаются обязательными. Retry подготовленного SHA повторно использует ту же версию.
